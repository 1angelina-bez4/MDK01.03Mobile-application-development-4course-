# МДК 01.03 «Разработка мобильных приложений»

Данный репозиторий содержит практические работы по междисциплинарному курсу МДК 01.03 «Разработка мобильных приложений», который входит в состав профессионального модуля ПМ.01 «Разработка программных модулей для компьютерных систем».

Курс предназначен для специалистов среднего звена по специальности 09.02.07 «Информационные системы и программирование».

## Цель

Основная цель этого репозитория — хранение и систематизация практических заданий, выполненных в Android Studio. Каждый проект демонстрирует разработку нативных Android-приложений с использованием современных инструментов и лучших практик.


## Технологии и инструменты

- Среда разработки : Android Studio Quail | 2026.1.4
- Язык программирования:  Kotlin

# MDK 01.03 "Mobile Application Development"

This repository contains practical work for the interdisciplinary course MDK 01.03 "Mobile Application Development", which is part of the professional module PM.01 "Development of software modules for computer systems".

The course is designed for mid-level specialists in the specialty 09.02.07 "Information Systems and Programming".

## Purpose

The main goal of this repository is to store and organize practical assignments completed in Android Studio. Each project demonstrates the development of native Android applications using modern tools and best practices.


## Technologies and Tools

- Dev environment : Android Studio Quail | 2026.1.4
- Programming languages:  Kotlin
